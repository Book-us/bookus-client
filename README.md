# 북커스, Bookus

<br/>

북커스는 책을 좋아하는 사람들이 모여 원하는 책을 검색하고 독서록을 작성하고 나만의 서재를 만들 수 있는 서비스입니다. 보다 세분화된 기록을 통해 나의 소중한 독서 경험을 간직할 수 있는 경험을 드립니다.

## 사용한 메인 라이브러리

<br/>

### 프론트엔드 라이브러리

- **React**
- **React Router DOM**
- **Recoil**

### 스타일링

- **Styled-components**

### API 통신

- **Axios**

### 빌드 및 개발 도구

- **Vite**
- **TypeScript**
- **ESLint
